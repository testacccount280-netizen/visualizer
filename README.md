# Skycoder — мини-апп для Telegram

Визуализатор Skycoder (кольца) в виде Telegram Mini App и обычного сайта. Код бота не меняется: мини-апп это отдельный сервис, бот лишь открывает его по кнопке.

Два режима звука:

| Вкладка | Что слушает | Как работает |
|---|---|---|
| **Это устройство** | микрофон устройства, на котором открыт мини-апп | `getUserMedia`; слышит музыку из динамиков этого устройства |
| **Компьютер** | системный звук вашего компьютера (песня в плеере, YouTube и т.д.) | страница `/host` на ПК захватывает звук и по WebSocket шлёт 10 значений в мини-апп |

**Общий эфир.** Если на сервере задан `PUBLIC_ROOM`, каждый, кто откроет мини-апп, сразу попадает на вкладку «Компьютер» и видит визуализацию вашей песни. Переключившись на «Это устройство», он видит реакцию на микрофон своего устройства. Когда вы не транслируете, зрители видят «Эфир сейчас не идёт» и подключаются сами, как только вы начнёте.

Почему «Компьютер» устроен через страницу `/host`: Telegram не даёт мини-аппам захват системного звука. Браузер Chrome/Edge на ПК это умеет, поэтому он снимает звук, а мини-апп (хоть на телефоне, хоть в Telegram на этом же ПК) получает уровни по коду. Передаются только 10 чисел, не аудио.

## Запуск на Render (1 раз)

1. Создайте на GitHub новый репозиторий (можно приватный) и загрузите в него содержимое этой папки (`server.js`, `package.json`, `render.yaml`, папка `public`).
2. На [dashboard.render.com](https://dashboard.render.com): **New → Web Service** → выберите репозиторий.
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Plan: Free
   (Если выберете Blueprint, всё подхватится из `render.yaml`.)
3. **Общий эфир:** в сервисе откройте **Environment** и добавьте две переменные:
   - `PUBLIC_ROOM` — любые 6 символов A–Z и 0–9, например `EFIR01`;
   - `HOST_SECRET` — ваш пароль передачи (длинный, придумайте сами). Без него транслировать в общий эфир нельзя, поэтому посторонний не сможет подменить звук.
   Сохраните, Render перезапустит сервис. Если переменные не задавать, всё работает как раньше: только личный код.
4. После деплоя Render выдаст адрес вида `https://skycoder-xxxx.onrender.com`. Откройте его в браузере: должны появиться кольца в демо-режиме.

> Бесплатный сервис Render засыпает после ~15 минут без запросов, первое открытие после паузы занимает до минуты. Для постоянной работы нужен платный план.

## Подключение к боту (без изменения кода бота)

1. Откройте [@BotFather](https://t.me/BotFather) → `/mybots` → выберите бота → **Bot Settings → Menu Button → Configure menu button**.
2. Отправьте адрес вашего сервиса (`https://skycoder-xxxx.onrender.com`), затем название кнопки, например `Skycoder`.
3. В чате с ботом рядом с полем ввода появится кнопка меню, она открывает мини-апп.

По желанию можно добавить прямую ссылку: BotFather → `/newapp` → выбрать бота → указать тот же адрес → получите ссылку `t.me/ваш_бот/короткое_имя`.

## Как пользоваться

**Звук устройства.** Вкладка «Это устройство» → «Включить микрофон» → разрешить доступ. На телефоне разрешение может понадобиться дать самому Telegram (Настройки телефона → Telegram → Микрофон).

**Транслировать свой компьютер для всех (общий эфир).**
1. На ПК откройте в **Chrome или Edge** `https://ваш-адрес/host`.
2. Режим «Общий эфир» выбран сам, если на сервере задан `PUBLIC_ROOM`. Введите `HOST_SECRET` (запоминается в этом браузере).
3. Нажмите «Начать трансляцию звука», выберите **«Весь экран»** и включите **«Поделиться звуком»**.
4. Всё: любой, кто откроет мини-апп, видит ваш звук. Страницу `/host` не закрывайте, можно держать в отдельном окне.

**Личная комната по коду** (если нужно показать только кому-то одному). На странице `/host` выберите «Личная комната», появится 6-символьный код. В мини-аппе: вкладка «Компьютер» → ниже «Свой компьютер: введите код» → «Подключить». Код запоминается.

Страницу `/host` можно держать в отдельном свёрнутом окне. Не закрывайте её во время прослушивания.

В обычном браузере на ПК на вкладке «Компьютер» есть ещё кнопка прямого захвата звука, без кода.

**Подключение без ввода кода.** На странице `/host` есть кнопки «Копировать код» и «Копировать ссылку». Ссылка вида `https://ваш-адрес/?code=XXXXXX` открывает сайт сразу на вкладке «Компьютер» и подключается сама. То же работает в Telegram: если открыть мини-апп по прямой ссылке с параметром `?startapp=XXXXXX` (после `/newapp` в BotFather), код подхватится автоматически.

**Только кольцо.** Нажмите на кольцо, пока идёт звук: интерфейс скроется, кольцо увеличится (в Telegram ещё включится полноэкранный режим). Повторный тап возвращает интерфейс.

## Эфир сам при включении компьютера (агент для Windows)

Страницу `/host` нужно открывать вручную и каждый раз выбирать «Поделиться звуком». Чтобы эфир стартовал сам вместе с Windows, используйте агента из папки `agent/`: он берёт системный звук напрямую, окон и браузера не нужно. Установка и автозапуск описаны в `agent/README.md` (Python + `install.bat` + ярлык в `shell:startup`). Агент и страница `/host` одновременно не нужны.

## Настройки (⚙)

Режимы (8 штук, перенесены из `modes.inc`), темы (8, из `themes.inc`), чувствительность, скорость вращения, размер, авто-усиление, вибрация на бит (только в Telegram). Настройки сохраняются на устройстве и в облаке Telegram.

По умолчанию стоит режим 8 «Custom» и тема «Gold», как в вашем `settings.inc`.

**Авто-усиление (включено по умолчанию)** подстраивает шкалу каждой полосы под громкость источника: тихий микрофон и громкий захват компьютера выглядят одинаково, а каждый бит доходит до максимума. «Чувствительность» в этом режиме задаёт, сколько dB ниже недавнего пика ещё видно: меньше = контрастнее, резче бит; больше = мягче, кольца горят дольше.

Если авто-усиление выключить, шкала станет фиксированной, как в Rainmeter (потолок −22 dB). Тогда чувствительность нужно поднимать вручную (30–50), иначе средние и верхние кольца почти не горят, особенно на микрофоне. Уровни считаются в браузере и не совпадают с Rainmeter один в один.

Если кольца светятся в тишине, значит микрофон очень шумный: выключите авто-усиление или уберите источник шума.

## Ограничения

- Работает только по HTTPS (Render даёт его сам); без него микрофон не включится.
- В Telegram Web и некоторых версиях Telegram Desktop микрофон может быть недоступен. Тогда используйте телефон или обычный браузер.
- Захват звука экрана умеют только Chrome/Edge на ПК. Firefox и Safari не отдают системный звук.
- К личной комнате по коду могут подключиться до 20 устройств, к общему эфиру до 300. С одного IP-адреса не больше 12 соединений.
- Общий эфир несёт только 10 чисел уровней, но бесплатный Render может не выдержать сотни зрителей одновременно: тогда нужен платный план.

## Локальная проверка

```bash
npm install
npm start        # http://localhost:3000
```

`localhost` считается безопасным адресом, поэтому микрофон работает и без HTTPS.

## Структура

- `server.js` — статика + WebSocket-релей (комнаты по коду, хранит только соединения)
- `public/index.html`, `css/`, `js/app.js` — интерфейс мини-аппа
- `public/js/engine.js` — расчёт Skycoder (Peak/Norm/Avg/Drive/Lvl, вращение)
- `public/js/audio.js` — микрофон, захват экрана, 10 полос 47–14000 Гц, приём с релея
- `public/js/data.js` — кольца, режимы, темы (сгенерированы из ваших `skycoder.ini`, `modes.inc`, `themes.inc`)
- `public/host.html` — страница-передатчик для ПК
